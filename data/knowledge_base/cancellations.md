# Order Cancellations

Northstar Shop is a fictional store. This policy is synthetic demo content.

## When an order can be cancelled

An order can be cancelled only while its status is "processing", which means it has not yet shipped. Cancellation requests are reviewed by a support agent, and a cancellation is not final until the agent confirms it.

## Orders that have already shipped

Once an order has shipped, it can no longer be cancelled. Instead, you can request a return after the package is delivered, following the returns policy.

## Pre-orders

Pre-orders can be cancelled at any time before the item ships, and you will not be charged a cancellation fee.

## Partial cancellations

You can request to cancel individual items in a multi-item order while the order is still processing. Shipping costs are recalculated for the remaining items.

## How to request a cancellation

Contact support with your order ID and the items you want to cancel. You will receive a ticket reference number. Do not assume the order is cancelled until you receive a cancellation confirmation from a support agent.
