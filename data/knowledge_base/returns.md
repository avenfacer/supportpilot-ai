# Returns and Exchanges

Northstar Shop is a fictional store. This policy is synthetic demo content.

## Return window

Most items can be returned within 30 days of delivery. Items must be unused, in their original condition, and in their original packaging with all accessories included.

## Items that cannot be returned

The following items are final sale and cannot be returned: gift cards, personalized or engraved items, clearance items marked as final sale, and opened in-ear headphones or earbuds for hygiene reasons.

## Exchanges

We offer exchanges for a different size or color of the same product, subject to availability. If the replacement item is unavailable, the exchange is processed as a return and refund.

## Return shipping costs

Return shipping is free if the item arrived damaged, defective, or was not the item you ordered. For all other returns, a $6.95 return shipping fee is deducted from the refund.

## How to start a return

Start a return by contacting support with your order ID and the reason for the return. Every return request is reviewed by a human support agent before it is approved. After approval, you will receive a prepaid return label by email. Submitting a request does not guarantee that the return will be approved.

## Damaged or defective items

If an item arrives damaged or defective, report it within 7 days of delivery and include photos of the item and the packaging.
